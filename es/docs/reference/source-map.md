## Regenerar documentación

```bash
POOL_SOURCE=/path/to/pool ruby scripts/sync_pool_docs.rb
python3 scripts/build_spanish_docs.py
```

La lista de verificación del creador de campañas sigue siendo una ruta pública propiedad de The Pool y no está
duplicado en este árbol de documentación para desarrolladores.
